# Business Research Portfolio

Interactive portfolio showcasing selected internship work across:

- Client research
- Pitch development
- Data-enabled research
- Regulatory interpretation

## Tech

- HTML
- CSS
- Vanilla JavaScript

No build step, no dependencies.

## Run locally

Open `index.html` directly in a browser.

## GitHub Pages

This project is designed to run as a static GitHub Pages site. All asset references are relative, so it works correctly at a project URL such as `https://USERNAME.github.io/REPOSITORY-NAME/`.
